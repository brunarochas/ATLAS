# ATLAS — Assistente de Organização de Estudos

Projeto desenvolvido em Python para organizar informações sobre a rotina de estudos, os interesses profissionais e os objetivos de aprendizagem do usuário.

> **Status:** Em desenvolvimento · **Versão:** 0.1

## Sobre o projeto

O ATLAS é um projeto pessoal criado durante meus estudos em Ciência da Computação. A proposta é desenvolver, gradualmente, um assistente que ajude a estruturar informações relacionadas à rotina de estudos.

A primeira versão utiliza conceitos fundamentais de Python, como entrada de dados, variáveis, conversão de tipos e saída de informações.

## Funcionalidades

- Coleta de informações do usuário.
- Registro do curso e da área de tecnologia de interesse.
- Registro da quantidade de horas de estudo por semana.
- Exibição de um resumo das informações fornecidas.

## Tecnologias

- Python 3

## Como executar

1. Instale o Python 3.
2. Baixe este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

   ```bash
   python atlas.py
   ```

   Se necessário, utilize `python3 atlas.py` ou `py atlas.py`, conforme a configuração do seu sistema.
